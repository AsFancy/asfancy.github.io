UCFPlugin

即装即用的UnrealEngine插件，可支撑数字孪生、智慧城市等行业的功能快速开发

用起来 说点什么

核心能力

统一接口入口

利用 UE 反射机制，支持蓝图、像素流、WebSocket 三种调用方式。

功能封装开箱即用

视点、标记物、测量、地形分析、空间分析、可视性、BIM 楼宇管理等接口可直接复用。

可扩展 Skill

标准化接口 Skill，配合 Agent 可扩展定制化接口。

模块构成

UCFCore

插件核心：GampPlay 框架、全局设置、统一接口调用入口、日志管理、坐标系。

UCFPlugin

接口实现层：视点管理、标记物管理、测量、地形分析、空间分析等功能接口。

UCFLibrary

函数库：Json 类型转换、数学计算、反射、资源管理等通用功能。

UCFEnhanceEditor

编辑器增强：以可视化界面封装 Python 脚本，实现编辑器内的快捷操作。

配套工具

UCFPixel

UCFPlugin 配套的像素流管理工具，也可独立使用。

UCFAgent

基于开源项目 Pi 二次封装的定制化 Agent，对 UCFPlugin 接口进行了二次封装，可直接用于驱动三维场景。
